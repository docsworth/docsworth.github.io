Docsworth
GitHub

Agents cite only the runbooks a team owns and has verified. For the rest, they say who owns it.

Your coding agents already read your runbooks. They can't tell a page verified last month from one nobody has touched in a year, so they cite both with the same confidence. Docsworth keeps your runbooks as markdown in your own repository, gives every page an owner and a review date, and lets agents cite only the pages that are current.

How it works

  • Runbooks are markdown in your own GitHub repository.
  • Each page has one owning team, enforced through CODEOWNERS, and a review SLA.
  • The MCP server lets agents cite only canonical pages within their SLA. Anything else comes back excluded, with its owner.
  • Docsworth never writes to your default branch: changes and verifications are pull requests to the owning team.
  • It runs on your machines with your GitHub identity. No hosted service, no telemetry, and agent reads are never metered.

Try it

You need Node 22.12 or later, a GitHub repository for your knowledge, and Claude Code.

npm install --global @docsworth/cli
cd your-knowledge-repo
docsworth init --team platform
docsworth lint .

claude plugin marketplace add docsworth/docsworth
claude plugin install docsworth@docsworth

Already have docs in markdown? docsworth adopt adds the frontmatter and turns site routes into .md links, as drafts your teams then verify.

The core is open source under Apache-2.0. Docsworth pro, a paid add-on under its own licence, adds a read-only Confluence and Notion mirror, the weekly owner digest, a coverage dashboard, an audit report and an accuracy benchmark.
